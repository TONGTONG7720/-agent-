# LLM 网关与端到端联调（llm-gateway/）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 LiteLLM 网关配置（多模型/多运营商 Key 统一 OpenAI 兼容接入），提供一键启动脚本与总 README，并完成无 Key 离线链路联调 + 真实模型冒烟指引。

**Architecture:** 网关纯配置无代码：`litellm-config.yaml` 注册通义/DeepSeek/智谱/自定义 OpenAI 兼容端点，Key 全部走环境变量（`.env` 不入 git）。联调分两层：①离线链路验证（无 Key）：启动 agent 服务→建任务→网关不可达→观察 `task_failed` 事件走通 SSE 全链路；②真实冒烟（有 Key）：跑 `agent/smoke_test.py`。

**对应设计文档：** 第 2.4、8 节

## 任务列表

### Task G1: 网关配置
- `llm-gateway/litellm-config.yaml`：注册 qwen-plus / deepseek-v3 / glm-4 / 自定义OpenAI兼容示例，`api_key: os.environ/XXX`；master_key 走环境变量
- `llm-gateway/.env.example`（真实 `.env` 已被根 .gitignore 排除）
- `llm-gateway/README.md`：pip 与 docker 两种启动方式、验证命令（curl /v1/models）

### Task G2: 一键启动脚本 + 总 README
- `scripts/start-all.ps1`：按序后台启动 gateway(4000)/agent(8001)/server(8080)/web(5173)，各自独立窗口
- 根 `README.md`：架构图、四模块导航、快速开始（前置依赖→启动顺序→默认账号）、常见问题

### Task G3: 离线链路联调（无 Key 可跑）
- 启动 agent 服务（内存 checkpointer、网关地址指向未启动的 4000 端口）
- `POST /agent/tasks`（auto_mode）→ SSE 应依次出现 pm 节点异常 → `task_failed`（LLM 不可达）
- 验证点：鉴权 401、任务启动 200、事件流含 task_failed 且 error 含连接失败——证明 API/编排/事件链路全通
- 真实冒烟指引写入总 README（需用户提供 Key 后执行）
